# 实验日志（huashu-flash 爬山循环）

每条：假设 → 最小改动 → 护栏 → 测量 → 去留。

## 第一轮（2026-10-24）

### 实验 1：rebuildCesium（生产构建压缩 + 摇树 Cesium）—— ✅ 保留

- **假设**：默认方案把 6.1 MB 官方预编译 `Cesium.js` 原样拷贝；改为
  `cesium({ rebuildCesium: true })` 从源码打包，经压缩/摇树后 gzip 传输可降
  ~25%，fast4g「能用」p75 相应下降。
- **改动**：`01_Web/vite.config.ts` 一行：`cesium()` → `cesium({ rebuildCesium: true })`。
- **护栏**：`npm run lint` 绿；`npm run build:public` 绿（3451 模块，1.10s）；
  preview 冒烟：地球画布渲染、瓦片 / Workers / SkyBox 贴图全部 200、控制台 0 错误。
- **配对测量**（A=原方案，B=新方案，交替 10 轮，fast4g）：
  - A：p50/p75/p95 = 4190/4205/4273 ms，13 请求，2.089 MB
  - B：p50/p75/p95 = 3093/3098/3105 ms，18 请求，1.586 MB
  - **能用 p75 降幅 26.3%**，传输 -24%。
- **代价**：Cesium 不再是独立稳定文件名 → 部署后应用更新，回访用户重下完整 JS；
  公开部署且重访大时可再拆 chunk（见报告建议项）。

### 实验 2：/media/user/ 缓存头 —— ✅ 保留

- no-store → `private, max-age=86400`（编辑器 API 保持 no-store）。媒体按 id
  一次性写入不覆盖，缓存安全；代价是删除后 ≤24h 内浏览器缓存可能仍显示。
  照片越多收益越大（画廊回访不再重下缩略图）。

## 第二轮（2026-10-26，用户反馈"页面感觉太慢"+ 移除鼠标跟随）

### 基线复测

生产 preview（4173，fast4g）能用 p75 = **3089 ms**，与第一轮优化后（3098）一致，
无回归。用户体感"慢"的构成为：首屏 1.36 MB 主包过代理（实测 ~4 s）+ Cesium
解析执行 ~1-2 s + 运行期 60fps 持续渲染的卡顿感。

### 实验 5：移除光晕 + 拖尾跟随效果 —— ✅ 保留（用户明确要求）

- **假设**（性能面）：拖尾每帧 rAF 绘制三层丝带 + 光晕/拖尾是叠在 WebGL 地球上的
  两个**全屏 mix-blend-mode 合成层**，加上 window 级 capture pointermove 监听，
  持续消耗合成器与主线程；移除后交互期卡顿下降。
- **改动**（worktree fix/remove-cursor-trail，commit 728caf2）：
  CesiumAtlasGlobe.tsx 删除类型/常量/辅助函数/8 个 ref/绘制与监听/减弱动效
  effect/JSX 两个元素（约 240 行）；index.css 删除四个选择器段与
  --cursor-x/y 自定义属性。JS -5 KB、CSS -1 KB。
- **护栏**：lint/tsc/build 全绿；浏览器冒烟：拖尾与光晕元素不存在、地球正常
  （canvas 2→1）、模拟 8 次 pointermove 无报错、控制台 0 错误。
- **测量口径说明（如实记录）**：bench 的 longtask 不含鼠标移动，拖尾收益无法
  用冷加载计时体现；以确定性计数佐证——rAF 常驻循环 1→0、window 级监听 1→0、
  全屏 mix-blend-mode 合成层 2→0。

### 实验 6：ion 域名 preconnect —— ✅ 保留（小额）

- **假设**：主包下载期间浏览器无法提前与 ion.cesium.com / assets.ion.cesium.com
  握手，首个影像瓦片多付 1-2 个 RTT；加两行 preconnect 提前建连。
- **改动**：index.html 两行（commit f4bdb4c）。
- **实测背景**：ion TTFB 笔记本经代理 0.19-0.38 s，mini 直连 0.66-1.28 s——
  走代理反而快，瓦片不是主要瓶颈；preconnect 是低成本顺手优化，预期省几百毫秒。

### 第二轮结论（剩余慢的归因与建议）

- 首屏 ~1.4 MB JS 已是 Cesium 应用的合理下限（压缩+摇树后），再降需放弃 Cesium。
- **国内用户最大剩余杠杆 = 换天地图影像**（CN CDN 直连，不过代理）：需用户去
  lbs.tianditu.gov.cn 申请 key 写入 06_private/config/.env.local 并重启构建。
- 运行期空闲渲染（60fps 常驻）仍是上游设计，建议提 issue 给上游（见报告）。
